## Owners and behavior
- components/AppShell.tsx owns shell geometry, safe areas, named root destinations and page Back. Existing useAppBack/history helpers own the logical destination/fallback.
- helpers/useRouteViewState.tsx stores bounded history-entry context in tab memory. useSavedControl separates entry restoration from durable view preferences; private typed queries are not saved across browser reloads.
- helpers/useRouteRestoration.tsx owns window scroll and originating-link focus restoration. It waits for delayed list content and yields to user scroll/keyboard interaction.
- helpers/shouldHandlePageBack.tsx and useEdgeSwipeBack yield to overlays, handled Escape, composing input and editable controls. Radix owns overlay focus/dismissal; portal popovers/dialogs carry data-ui-overlay.
- components/SearchField.tsx owns accessible search/Clear with a 44px target and return-to-input focus. helpers/useSearchTerm.tsx waits for composition completion and debounces remote terms; empty search clears immediately. Catalog queries additionally gate old results by the active trimmed term.
- base.css owns palette-aware visible scrollbars and focus scroll clearance. Seeded controls remain the baseline. Home feature geometry has one responsive owner in pages/_index.module.css; readable titles/actions may increase card height.
- Home posters/covers use object-fit: contain in stable aspect-ratio frames; never stretch them to text height or trim the source to fill the frame. GameDeck reserves 3:4 cover frames and Marquee 2:3 poster frames. Home decorative backdrops also fit completely. Missing/broken artwork preserves reserved dimensions and a fallback; fade backdrop artwork only, never content or controls.
- Keep success/Undo separate from persistent errors; initial and background failures retain explicit Retry without manufacturing history.

## Marquee decisions
Home is a glanceable, automated-progress surface: no Mark watched/check-in controls on featured or continuing titles. Keep View next episode and title links; manual marking remains in title/episode details. Existing sync automation and watch history are unchanged.
Watch List begins with useful controls; keep its accessible shell heading and remove the duplicate decorative title/intro. Failed Undo has a separate alert and retry while the removal context remains available.
Season/series catch-up confirms title/scope, missing count and unknown air dates; Cancel performs no mutation, pending submissions are disabled, errors stay in the dialog and successful catch-up retains existing Undo. The existing catalog treats unknown air dates as eligible; disclose them rather than implying confirmed release dates. Season progress counts only known released catalog episodes. Home and the detail summary use synced title totals. If those sources disagree, season labels, the index note and bulk confirmation explicitly name the catalog basis and both totals. Actual staged review found synced 48 versus catalog 49 for The Apothecary Diaries; this UI pass leaves source records unchanged. Show unknown air-date counts separately; bulk-action eligibility additionally includes those unknown dates and discloses them in confirmation. Home artwork uses MediaImage fallback.
Focused action-safeguard tests exercise failed Undo, Cancel/no-write, bulk errors and broken-image fallback using isolated mocked requests, never owner data.
